## 我怎样推进 AI 产品

1. **先定义交付**：明确谁在什么场景完成什么任务，把 AI 能做的部分、人工确认点和验收要求写清楚。
2. **再评测和取舍**：统一任务、输入与评分口径，保留失败案例；结合质量、预算和响应时间选方案。
3. **把控制权交给用户**：在剧本、分镜等关键节点确认，支持定位和局部修改，减少前序错误传递。
4. **用证据推进迭代**：把问题定位、修改动作、复验结果和版本关联起来，让团队按同一标准协作。
