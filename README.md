## 我关心的产品问题

**用户为什么需要它？** 从具体任务出发，明确场景、痛点与使用路径。

**AI 到底改善了什么？** 关注结果质量、操作成本、失败情况与人工接管，而不只看演示效果。

**怎样让产品交付后继续可用？** 把需求、测试、使用说明与后续改进一起留下，让实践能被复盘、复用。
